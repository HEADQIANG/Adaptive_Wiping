## 2. 仿真与数据采集

**复用现有适配，先修正控制语义。** 已实测当前 `clean` 环境能创建 AIRBOT 擦拭场景并读取六维力，但现有 XML 的位置执行器与 `JOINT_POSITION` 控制器输出的力矩不匹配。预训练环境采用独立配置和编译前模型覆写，不改动已有鼠标示教默认行为。

- **执行链路：** 明确加载预训练控制器配置，使用 `WHOLE_BODY_IK → JOINT_POSITION → motor`。保留 AIRBOT 几何、惯性和关节限位；力矩执行器初始限幅参考本地 DISCOVERSE 力控模型，前三轴 ±10 N·m、后三轴 ±5 N·m，仅作为仿真配置，不视为厂家额定值。预训练副本的关节 `frictionloss` 设为 0，避免沿用未标定的 15/5 阻力；该差异写入报告。
- **控制参数：** 仿真步长 0.002 秒，动作更新与采样均为 100 Hz，每次动作推进 5 个物理步。IK 使用世界系绝对位姿、固定工具朝下姿态，积分周期改为 0.01 秒。关节控制采用临界阻尼，依次测试增益 100、300、1000，选择首个通过轨迹验收的配置后对整批数据冻结；全部失败则停止采集，不自动放宽力矩限幅。
- **场景：** 使用 `Wipe` 派生的专用探索环境，保留桌面和传感器，关闭相机、污渍奖励计算及任务成功终止。固定桌面高度、机器人初态和工具尺寸，仅随机化海绵接触参数；不加入额外视觉、噪声或延迟随机化。
- **参数映射：** 三个参数独立均匀采样；设 `geom_friction[0]=μ`、`solref=(-k,-2√k)`、`solimp=(0.2,0.9,width,0.5,2)`。固定扭转/滚动摩擦为 `0.005/0.0001`，统一更新所有擦拭头碰撞几何；工具接触优先级高于桌面，并检查实际生成接触的参数，防止桌面摩擦覆盖采样值。
- **解释边界：** 上述 `k` 是 MuJoCo 直接形式的约束刚度项，不能直接宣称等于 N/m；阻尼关系、其余 `solimp` 参数和均匀分布均是补全约定，不是作者公开实现。不额外添加弹簧海绵或软体结构。
- **起点与动作：** 在桌面近机械臂一侧设置固定探索中心，默认世界坐标 XY 为 `(0,0)`；根据工具碰撞几何计算竖直起点，使其最低点距桌面 1 mm。通过位置控制到达并稳定后开始计时，按压 2 秒，再保持目标高度沿世界 Y 轴移动 +50 mm、−50 mm。就位过程不计入 4 秒，探索期间禁止直接修改 `qpos` 或用恒力控制改变动作。
- **数据读取：** 读取更新后的腕部 `force_ee`、`torque_ee`，保留传感器局部坐标系和原始符号，不以关节力矩或单个接触点法向力替代。主数据不做逐轨迹清零；额外保存悬空偏置、传感器姿态、实际 TCP 和目标 TCP，便于解释重力及跟踪影响。
- **采样与保存：** 按仿真时间记录 `0.01…4.00 s` 的 400 帧。HDF5 保存六维力、时间戳、实际/目标位姿、接触状态、参数、随机种子和有效性。参数只用于诊断，不输入 VAE，也不作为监督标签。
- **数据数量：** 1000 条训练轨迹，另采集 100 条验证、100 条测试，三组使用独立种子并按整条轨迹隔离。先固定参数清单再采集；失败保留原因，不静默换参数补足数量，也不把低刚度或低摩擦产生的小信号当作无效样本。

## 3. 预处理与 VAE

**预处理默认值：** 对每条 100 Hz 序列沿时间轴应用二阶、10 Hz Butterworth 零相位滤波；再按训练集所有轨迹共同计算的六通道 min/max 映射到 `[0,0.9]`。验证、测试和后续真实探索只复用这些统计量，不重新拟合、不逐条归一化、不静默裁剪越界值。常量通道使用显式掩码避免除零。滤波参数属于工程补充。

按原文“逐帧 5 维隐藏表示、展平、5 维高斯潜变量”的描述，固定以下可执行结构：

```text
输入 [B,400,6]
→ Linear(6,5)，逐帧共享权重
→ Flatten → [B,2000]
→ Linear(2000,10)，拆分为 μ、logvar，各 [B,5]
→ 重参数化 z = μ + exp(0.5×logvar)×ε
→ Linear(5,2000) → ReLU → Dropout(0.1)
→ Reshape [B,400,5] → Linear(5,6)
→ 重建 [B,400,6]
```

编码器不额外增加原文未说明的激活或 dropout，输出层保持线性；均值/方差头的拆分方式属于补充约定，不能改成任意大规模 MLP 后仍称为同一结构。

- **损失：** `L=MSE(reconstruction,input)+0.06×KL(q(z|x)||N(0,I))`。MSE 对批次、时间和通道取平均；KL 对 5 个潜变量求和，再对批次取平均。固定并记录这一归约方式，避免同一个 β 对应不同训练强度。
- **训练默认值：** batch size 32，Adam `betas=(0.9,0.999)`、`eps=1e-8`、weight decay 0，随机种子 42，float32；不加学习率调度、KL 退火或数据增强，完整运行 200 epochs。
- **检查点：** 保存每轮训练/验证的重建项与 KL，导出第 200 轮模型作为主结果，同时保留最佳验证模型作诊断，不用提前停止替代论文轮数。
- **后续接口：** 提供 `encode(raw_ft[B,400,6]) → μ[B,5]`，内部复用固定预处理。导出编码器权重、结构参数、滤波器、归一化统计、通道顺序与坐标系；推理时使用 `eval()` 和均值，不随机采样。

## 4. 实施步骤与验收

实现放在当前工程新增的 `scripts` 包中，按仿真采集、预处理、VAE、训练评估划分模块；主配置为 `configs/sim_pretrain/pretrain_paper.yaml`。复用本地 robosuite，不直接修改其通用 `WipingGripper` 参数文件或覆盖现有用户改动。

统一入口现已实现，执行状态和依赖见 `docs/sim_pretrain/pretraining.md`。以下命令须按顺序执行，物理验收失败时禁止跳过检查进行采集：

```bash
python -m scripts.sim_pretrain sanity --config configs/sim_pretrain/pretrain_paper.yaml
python -m scripts.sim_pretrain collect --config configs/sim_pretrain/pretrain_paper.yaml
python -m scripts.sim_pretrain train --config configs/sim_pretrain/pretrain_paper.yaml
python -m scripts.sim_pretrain evaluate --config configs/sim_pretrain/pretrain_paper.yaml
python -m scripts.sim_pretrain export --config configs/sim_pretrain/pretrain_paper.yaml
```

1. **控制与物理验收：** 先验证悬空保持、按压、卸载、横移和偏心施力；无接触路径位置 RMS 误差 ≤1 mm、姿态误差 ≤1°。用三个参数各取端点及中点形成 27 组扫描，报告接触期间跟踪误差、力矩饱和和力曲线，确认实际参数生效后才启动全量采集。
2. **数据验收：** 训练集严格为 `1000×400×6`，验证和测试各 `100×400×6`；时间连续、数据有限、无非工具碰撞和仿真自动重置。禁止补零伪造完整轨迹，禁止以丢弃极端参数样本来掩盖系统性问题。
3. **代码测试：** 覆盖阶段边界、参数映射、接触优先级、传感器通道、滤波轴、训练集归一化隔离、VAE 张量形状、标准正态 KL 为零、梯度有效及保存加载一致性。
4. **模型验收：** 报告六通道原始单位 RMSE、归一化 MSE、KL 和潜变量变化；与“训练集平均轨迹重建”比较，并通过固定/打乱潜变量检验解码器是否真正利用编码。出现潜变量坍塌时如实报告，不静默修改 β 或网络来制造成功结果。
5. **交付与文档：** 输出数据集、采集失败清单、训练曲线、测试重建图、完整 VAE 与冻结编码器、环境版本及模型配置摘要。在 `docs/sim_pretrain/pretraining.md` 写清安装、上述命令、预期产物及故障检查；每次代码变更后同步核查运行步骤，并更新已有总方案中不再适用的低速预训练描述。

最终验收对象是“按明确配置训练得到、可重复调用的 5 维探索表征编码器”，不是擦拭成功率或真实物性参数预测器。
