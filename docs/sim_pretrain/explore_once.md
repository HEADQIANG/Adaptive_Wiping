# 单次仿真探索与实时六维曲线

当前默认配置已启用每段起止各 0.2 秒平滑加减速，总时长和位移不变。
可用 `--ramp-s` 调整；峰值速度及真机协议差异见 [平滑探索](smooth_exploration.md)。

当前默认配置启用均匀箱体海绵惯量，命令无需增加参数。
新旧数据不可混用，详情见 [工具惯量说明](sponge_inertia.md)。

2026-09-12 方向调整：按用户要求，Fy、Fz、Ty、Tz 取反，Fx、Tx 保持不变。
实时曲线与保存的 `ft` 同步采用
`(ft_raw - initial_bias) * [1,-1,-1,1,-1,-1]`。
`ft_raw`、`initial_bias` 和 `sensor_quat_xyzw` 仍为原始 MuJoCo 传感器坐标约定；
如需将新 `ft` 转到世界坐标，须先撤销该输出符号变换再应用原始传感器旋转。
该调整仅改变六维输出，不改变机械臂运动、接触物理或 MuJoCo 传感器安装。
这是指定的方向对应关系，不代表完成真机外参或载荷标定。
新元数据标记为 `initial_noncontact_tare_yz_flip_v2`，并记录 `ft_output_signs`。
运行命令不变，重新运行下方命令生成新的单条数据和曲线；不覆盖旧结果。
旧版清零数据及模型不可与新方向的数据混用。

在项目根目录、有桌面显示的终端运行：

```bash
MPLBACKEND=TkAgg /home/wp/miniconda3/envs/clean/bin/python -m scripts.sim_pretrain explore-once \
  --mu 1.2 --stiffness 500.25 --width 0.16 --gain 300
```

每次只运行一次探索，不启动批量采集、sanity 参数扫描或训练。
曲线窗口先打开，然后机械臂完成准备动作；稳定悬空后清零，打开 MuJoCo 窗口，
画面与曲线随同一次探索同步更新。MuJoCo 画面从探索起点开始，不播放准备动作。
默认同时显示两个窗口，无需增加开关。画面使用独立模型和状态，
窗口内相机操作或鼠标扰动不会写回采集仿真。
显示的是初始清零后的传感器局部六维数据，不是预先计算后播放。
探索按墙钟尽量以 1 倍速显示；机器或绘图较慢时可延长实际等待时间，
但仿真步长、100 Hz 采样和 4 秒轨迹不改变。
完成后保留两个窗口和最终状态，关闭两个窗口后退出。
探索中提前关闭任一窗口会中止，不保存为完整轨迹。

可手动修改命令参数：

| 参数 | 含义 |
| --- | --- |
| `--mu` | 滑动摩擦系数，非负 |
| `--stiffness` | MuJoCo 接触直接刚度项，正值；阻尼同时按 `2*sqrt(k)` 设置，不是标定的 N/m |
| `--width` | `solimp` 接触阻抗过渡宽度，正值；不是海绵几何尺寸 |
| `--gain` | 有限正数关节位置控制增益，可超过 1000 用于诊断；不属于海绵属性，执行器限幅不变 |
| `--ramp-s` | 每段加速/减速时间，范围 `[0,0.5]` 秒，当前默认 0.2；0 恢复旧速度阶跃 |
| `--output` | 可选的新输出目录；已有目录拒绝覆盖 |
| `--no-viewer` | 只显示曲线，不打开 MuJoCo 窗口 |
| `--close-after-run` | 保存后自动关闭两个窗口，适合单次验证 |

默认保存到 `runs/sim_pretrain/explore_once_<时间戳>/`：

- `exploration.npz`：一条 `400×6` 的 `ft`，同形状 `ft_raw`，六维 `initial_bias`，时间、位姿、接触数和其他诊断字段。
- `ft.png`：本次六维曲线截图。

NPZ 的 `metadata_json` 包含配置、参数、坐标系、单位和跟踪指标。
绘图额外显示 `t=0` 的零点，但保存的探索仍为 `0.01–4.00 s` 共 400 帧。
这是单次诊断数据，不意味着通过正式训练采集验收。

动作阶段时长和位移与当前真机标准协议一致：下压 2 秒 / 10 mm，然后沿 +Y、-Y
各滑动 1 秒 / 50 mm。但仿真已加入平滑加减速，逐点目标和峰值速度不再与真机相同。
显示同样减去起点基线；真机使用一段静止采样的均值，
仿真使用稳定起点读数，没有模拟真机电子噪声。不会连接或控制真机，
也不会执行真机的 2 秒回撤。材料、惯性、控制器和标定误差仍会造成力值差异。
起点清零消除静态重力分量，不是动态重力补偿；悬空运动时读数不保证恒为零。
