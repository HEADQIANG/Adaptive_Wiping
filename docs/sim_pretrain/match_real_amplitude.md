# 与真机 003 的幅值对照搜索

## 随机化覆盖诊断

在项目根目录运行下列命令，生成 128 条独立诊断轨迹，不启动训练或真机：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  /home/wp/miniconda3/envs/clean/bin/python -m scripts.sim_pretrain.experiments.match_real_amplitude \
  --random-samples 128 --seed 20260912 --gains 2000 10000 --mu 0.4 1.0 \
  --stiffness 100 10000 --width 0.001 0.1
```

`--random-samples` 启用 Latin hypercube 分层随机采样，各参数必须提供两个端点。
mu 均匀，其余三项对数均匀；每条动作参数恒定，seed 和所有采样值保存在报告。
不指定该选项时仍使用原笛卡尔网格。默认动作 4 秒，平滑段 0.2 秒，目标位移不变。

新输出 `coverage.png`、`coverage.npz` 及报告 `coverage` 分别记录全部完成轨迹、
零限幅轨迹、原运动验收通过轨迹。空组标为 no_candidates，不报告虚假的零误差。
逐通道、逐时刻的 min/max 包络覆盖不等于六维联合覆盖，也不等于存在完整匹配轨迹。
报告另外计算同一时刻由同一候选满足六通道容差的比例，以及单条候选全程满足容差的数量。
容差为各通道真机绝对值 P95（尺度下限 0.5 N / 0.01 N*m）的 10%，仅为诊断阈值，
不修改原运动验收；不拟合输出增益或时间偏移。阶段窗口同下文。

### 结论边界

本次范围内没有找到六通道幅值接近且运动合格的组合；不证明所有未搜索参数均无解。
gain=300 的第一轮按压末段绝对 Fz 仅 1.34-1.72 N；gain=1000 为 2.30-5.78 N。
扩大接触刚度至 20000 后，两轮按压末段绝对 Fz 最高仍仅 5.80 N。
全部候选均未触发执行器限幅，不能把缺力简单归于力矩上限。
需要优先验证实际 Z/姿态保持与控制参考，而不是继续盲目提高材料刚度。
最佳候选正向合力均值向量的模长为 4.01 N，真机为 12.08 N，差异不只是轴向投影。
但其 XY 合力方向与真机还差约 26 deg，Y/Z 符号对应不等于完整坐标标定；
后续同时匹配 Fx/Fy 及力矩还需核对传感器安装角和作用点，不能用输出放大替代。

### 扩展后的结论

增益超过旧范围后能够补足 Fz，故旧搜索中的幅值不足不能单归于材料刚度。
但更高增益不单调改善拟合；本轮部分高增益候选发生限幅，最大饱和帧比例 41.5%。
上述两个候选均未饱和，残差仍表现为 Fy/Tx 偏小、运动和姿态保持不一致。
只改材料和统一关节增益尚未找到六通道、波形和实际动作同时接近的组合。
下一步应核对传感器完整安装旋转/力矩作用点，以及真机伺服与仿真位置/姿态跟踪，
不建议把这两组诊断参数直接当作已标定的训练参数。

验证：33 项回归测试通过；新增 135 条 NPZ 均为有限 400x6 数据，
已复算全部评分并核对参考日志 SHA256 与报告一致。批量诊断未启动真机或训练。
