## 1. 阅读口径与当前结论

| 类别 | 含义 |
| --- | --- |
| 运行保护 | 运行检查发现超限后抛出异常；已接管且进入控制流程时尝试软件停止。不是硬件实时急停保证 |
| 门禁 | 不允许启动、接受数据、继续正式采集、评估或导出；不等于机械臂当时必然执行停机 |
| 质量判据 | 判断运动或模型质量；可能在轨迹结束后计算，不是实时停止条件 |
| 仅记录 | 保存误差、警告或超限标记，但该项本身不阻止继续 |
| 人工确认 | 现场核实非接触、完整路径、实际接触效果、支撑和急停；配置里的 `true` 只记录确认 |

关键结论：

- 当前真机探索和程序示教继承 `tracking_error_policy=record-only`，运行位置和姿态误差均只记录。固定安装推理分别将位置、姿态策略设为 `record-only`。
- 起点和最终回位资格不因上述策略取消；程序示教的启动直达还有独立的严格跟踪检查，不能与固定安装推理混淆。
- 当前拖拽示教的力/力矩、速度均为 `record-only`，不能套用程序示教的 40 N / 0.8 Nm / 1.2 rad/s 停机规则。
- 全局 `workspace_min_m/workspace_max_m` 已移除；关节范围、无力接触压缩预算、空中净空及固定安装推理的任务相对边界仍存在。
- 仿真严格采集与研究型不筛选采集是不同入口。研究数据 `valid=true` 不证明接触运动达标。
- 当前没有统一的“擦拭成功率达到多少”“法向力误差超过多少就停”“真机预测 RMSE 必须小于多少毫米”的自动验收标准。
- 本次只读固定安装预检：`offline_inputs_valid=true`、`run_enabled=false`，阻断项为 `Fixed-setup replay failed or is stale`，退出码 2。未重新回放、未修改绑定、未连接硬件。

下表中的 `>` 通常表示严格大于才失败，等于阈值通过；个别截止时间使用 `>=`，已单独注明。位置误差若未注明分量，指三维欧氏距离；关节速度为任一轴绝对值；力和力矩为各自三维合量，不是单轴 Fz/Tz。

## 2. 真机共享保护与起点资格

### 2.1 当前带力保护流程

适用于 `airbot_exploration.json` 的 force-guarded 探索及继承它的程序示教。固定安装部署读取已绑定 `session.json` 的冻结配置，不读取后来修改的探索配置；该部署文档记录的冻结数值与下表相同。

| 项目 | 当前数值/条件 | 失败处理或限制性质 |
| --- | --- | --- |
| 运行合力 | `norm(F) > 40 N` | 运行保护 |
| 起点/基线合力 | `norm(F) > 32 N` | 拒绝基线或起点资格；已控制时进入异常停止流程 |
| 合力矩 | `norm(T) > 0.8 Nm` | 起点和运行均保护 |
| 力信号新鲜度 | 接收年龄必须在 `[0,20 ms]`，数据存在、6 维、有限 | 过期、未来时间戳、缺失或非有限数据拒绝 |
| 关节命令限速 | `0.4 rad/s` | 设置/发送给 SDK 的限速，不是实测停机阈值 |
| 实测关节超速 | 任一轴 `abs(qdot) > 1.2 rad/s` | 运行保护 |
| 关节电流参数 | 六轴均为 `8.0` | 传给 SDK 的 `eff` 参数；不是本项目循环内独立测量电流并比较的验收，也不能视为额定安全电流 |
| 起点位置 | 与记录起点距离 `<=2 mm` | 超过则起点不合格；通用公式 `min(2 mm, tracking_limit)` |
| 起点姿态 | 四元数角距离 `<=0.02 rad`，约 `1.146°` | 超过则起点不合格，不沿用运行姿态放宽值 |
| 起点关节分支 | 每轴相对记录角度差 `<=0.03 rad`，约 `1.719°` | 超过则拒绝，不自动换 IK 分支 |
| 设备与控制状态 | 机器人序列号、NULL 末端身份、预期控制模式匹配；服务有效，无电机错误，控制权存在 | 失败拒绝/中止，不自动抢回控制权 |
| SDK 返回姿态 | 四元数模长与 1 相差不得 `>0.01`；位姿和关节值有限 | 非法反馈拒绝 |
| 通用状态读取 | `snapshot` 完整读取耗时 `>0.5 s` 拒绝 | 某些入口另有更严格的 20 ms 或周期检查，不应把 0.5 s 当作全部流程容许延迟 |
| RPC 截止 | 共享包装普通 RPC 默认 50 ms；切控制器 1.5 s | 通信超时边界，不是运动周期或硬件停止时间保证 |

实际受力检查使用 `raw_sensor_wrench - sensor_bias_si`，保留重力；当前偏置六轴均为 0，因此等同原始载荷。每次空载基线扣除仅用于记录/模型输入，不降低上述安全检查中的原始载荷。32 N 通过不证明工具真的离面，仍须目视确认。

共享关节角范围如下，边界包含端点，运行超出配置区间则拒绝/停止：

| 关节 | 最小角 | 最大角 |
| --- | ---: | ---: |
| J1 | -180° | 120° |
| J2 | -170° | 10° |
| J3 | -5° | 180° |
| J4 | -172.5° | 172.5° |
| J5 | -105° | 105° |
| J6 | -172° | 172° |

### 2.2 静止、清零与空载记录

| 场景/项目 | 必须满足的条件 | 不满足时 |
| --- | --- | --- |
| 记录初始位姿、普通探索清零的静止速度 | 每轴 `abs(qdot)<=0.05 rad/s` | 拒绝记录/清零 |
| 程序示教、固定安装推理的静止速度 | 每轴 `abs(qdot)<=0.1 rad/s` | 基线阶段仅静止失败可在总预算内重采；不是运行超速阈值 |
| 共用静止变化量 | 至少 11 个状态；每轴关节角跨度 `<=0.01 rad`；任意两帧位置距离 `<=2 mm`，姿态角距离 `<=0.02 rad` | 不算静止，往返漂移也不能通过 |
| 普通探索清零 | 已确认 1 mm 非接触间隙；采约 1 s；至少 20 个不同接收时刻，覆盖 `>=0.9 s` | 拒绝；接收时钟倒退也拒绝 |
| 程序示教/固定安装新基线 | 每条重新采 1 s；至少 40 个不同接收时刻，覆盖 `>=0.9 s`；全过程起点与静止合格 | 不稳丢弃整段；总计 10 s 含停稳、采样和重试，超时中止 |
| 基线不可重试故障 | 起点偏离、过力、运行超速、断流、时钟倒退、同时间戳冲突、失控、I/O 异常 | 不享有静止重试例外 |
| 程序示教/固定安装最终停稳 | 通常限时 2 s；连续最近 11 帧均满足起点位姿、关节和静止标准 | 超时停止，不能因命令已发完而判回位成功 |
| 独立空载姿态采集 | 人工确认无接触；观测跨度 `>=1.9 s`；至少 20 个不同 FT 时刻；FT 年龄 `[0,50 ms]`；控制模式不变；默认静止标准合格 | `eligible_unloaded_pose=false` 或采集失败；此处 50 ms 不适用于运动中的 20 ms 保护 |

## 3. 真机采集各入口的差别

### 3.1 探索 force-guarded

| 检查 | 代码默认规则 | 当前配置实际行为 |
| --- | --- | --- |
| 位置跟踪 | 误差 `>5 mm` 停止 | `tracking_error_policy=record-only`，只记录，不停 |
| 姿态跟踪 | 默认 `>0.02 rad` 停止；允许配置其他上限 | 当前参考值 `0.15 rad`，约 `8.594°`；受同一 `tracking_error_policy` 控制，只记录，不停 |
| 滑动分量 | 默认 `abs(slide_error)>5 mm` 纳入停止检查 | `lateral_tracking_policy=record-only`；当前又启用整体 record-only，所以位置全部分量均不因跟踪超限停止 |
| 发送截止 | 发送前当前时间 `>due` | 中止，不追赶补发 |
| 采样迟到 | 观测完成相对计划时间 `>5 ms` | 中止 |
| 起点资格 | 2 mm / 0.02 rad / 0.03 rad | 仍严格执行 |

`lateral_tracking_policy=record-only` 单独启用时，仅忽略滑动方向，仍检查法向和横向正交误差合量；不能将其与整体 `tracking_error_policy=record-only` 混为一谈。

探索协议为 4 s、100 Hz、400 个积分后样本，前 2 s 下压 10 mm，再 1 s 前移 50 mm、1 s 返回；另用 2 s 正常回撤 10 mm。**10 mm 是探索名义命令深度，不是该 force-guarded 独立入口已实现的实测深度停机阈值**：`check_compression` 仅在 contact-no-ft 生效；程序示教和固定安装推理另行实现了实测 20 mm 保护。

`--time-scale` 必须在 `[1,10]`，可减速，不允许比仿真协议更快；减速时实际采样数随时长增加，只有 1 倍时长匹配原 400 帧协议。完成命令、记录 400 帧或回撤命令完成，不自动证明真实探索达到仿真 1 mm RMS/接触运动标准。普通探索也不能套用程序示教的最终实测回位验收。

出处：[探索实现](../scripts/real_training/airbot_exploration.py)、[统一探索协议](../scripts/shared/exploration_protocol.py)、[探索操作说明](real_training/airbot_exploration.md)。

### 3.2 程序固定深度示教

| 检查 | 当前标准 | 结果 |
| --- | --- | --- |
| 启动直达速度/时长 | 平移 0.01 m/s、转动 0.1 rad/s；计划时长不得超过 60 s | 超长路径启动前拒绝，不自动绕行 |
| 启动直达跟踪 | 位置误差 `>5 mm` 或姿态 `>0.02 rad` | **独立严格停止**，不受继承的擦拭运行 record-only 取消 |
| 启动观测 | 状态读取 `>20 ms` | 停止 |
| 启动节拍 | 100 Hz；唤醒迟到 `>5 ms`；各阶段和含日志整轮预算 10 ms | 超时停止，不追赶 |
| 命令深度 | nominal=10 mm、under=8 mm、over=12 mm；目标总下压必须在 `[0,20 mm]` | 越界拒绝 |
| 实测总下压 | 相对起点沿法向 `>20 mm` | 启动、擦拭和回撤的观测均中止 |
| 擦拭位置/姿态 | 继承探索的 5 mm / 0.15 rad 参考值 | 当前仅记录，不以偏差自动拒收，需人工看实际轨迹 |
| 擦拭时序 | 发送前 `now>=due`，或采样迟到 `>5 ms` | 停止 |
| 回撤时序 | 单阶段相对重排计划迟到 `>10 ms`；全回撤超过名义时长加 1 s | 停止；发送至少间隔 10 ms，不追赶；2 s 最终停稳预算另算 |
| 示教接受 | 时序质量合格、正常结束、实测回位通过，并由操作者输入 `a` | 不合格不得接受，拒绝重采；不能把命令完成当作有效接触 |
| 数量/顺序 | 8 条连续编号；nominal、nominal、under、over、under、over、under、over | 顺序、原始文件哈希、协议和完整性不符则拒绝导出 |
| 会话冻结 | 配置、起点与已有会话一致 | 变化后必须新会话，不能混采 |

这些是固定深度运动，**没有目标法向力、没有恒力控制，也没有法向力误差停机条件**。名义 ±50 mm 横向路径不是此入口的全局软件避障范围。

时序数据验收要求：位姿和 FT 完整覆盖实际记录区间；位姿严格递增，相邻间隔 `<=20 ms`；FT 接收时刻不倒退、不同帧间隔 `<=20 ms`；位姿周期中位数在 `[9,11] ms`；单次状态读取 `<=20 ms`；观测对位姿的主机时间差在 `[0,20] ms`。程序示教比较中部分上界另加 `1e-9 s` 数值容差。

### 3.3 人工拖拽示教

当前默认软件清零并实时显示六轴曲线：每次连接先 `z` 确认无接触并采 1 秒基线（不同接收数至少 40、跨度至少 0.9 秒、接收间隔不超过 20 ms）。录制与 CSV 同时保留原始值和清零值；力保护不改用清零值。具体运行与新旧会话边界见 [清零与实时曲线](real_training/manual_tare_live_plot.md)。

2026-09-15 起取消录制前静止验收：输入 `s` 后读取一次有效状态作为起点，不再采集 11 帧检查速度或位姿变化。起点位置、朝向相对参考的偏差仍仅记录；不影响独立起点记录、程序示教等入口的静止检查。

当前 [拖拽配置](../configs/real_training/airbot_demonstrations.json) 将 `workspace_force_policy`、`joint_speed_policy` 均设为 `record-only`，力/力矩和速度阈值为 `null`。因此没有启用相应超限自动停机，软件也不保证承重。仍检查关节角范围、数据有效性、力流 `[0,20 ms]` 新鲜度、控制权、设备健康和预期重力补偿模式。

每条实测 10 s，100 Hz 名义采样，共 8 条；采后要求完整覆盖、位姿/FT 间隔 `<=20 ms`、位姿周期中位数 9–11 ms、读取耗时 `<=20 ms`，再人工接受。时序不合格是拒收条件，不应表述为全部都在每个循环实时停机。接受文件还要通过编号、原始日志哈希和完整性复查。现场准备以 `--execute` 明确授权，不再输入启动口令；当前 `setup_confirmed=false` 的处理详见入口，不能把它直接等同于程序示教的配置放行规则。

出处：[拖拽实现](../scripts/real_training/airbot_demonstrations.py)、[拖拽操作](real_training/airbot_demonstrations.md)。

### 3.4 空中运动和无力接触

| 模式 | 标准 | 当前情况 |
| --- | --- | --- |
| air 空中运动 | 起点净空至少 50 mm；估算剩余净空 `<20 mm` 停止 | 当前 air 配置命令/实测速限均 0.4 rad/s；无力传感器保护 |
| air 跟踪/起点 | 运行位置 5 mm、姿态 0.02 rad；起点位置按当前共享代码为 2 mm | 超过停止/拒绝；旧文档中 1 mm 起点描述不代表当前代码 |
| contact-no-ft 跟踪 | 当前示例位置 0.5 mm；姿态 0.02 rad；命令/实测关节速度 0.2 rad/s | 无力数据，禁止 record-only 放宽；当前确认和几何参数未完成，不能运行 |
| contact-no-ft 启动预算 | `10 mm - 1 mm间隙 + 位置容差 + 几何不确定度 + 储备 <= 已确认压缩量` | 不满足则拒绝启动 |
| contact-no-ft 实测压缩 | `max(0, 实测下移 - 1 mm + 几何不确定度) <= 已确认压缩量 - 储备` | 超过则停止；示例压缩量 20 mm、储备 0.25 mm，几何不确定度仍未填 |

净空/压缩是基于记录起点和几何声明的估计，不是实时测距、碰撞检测或实际接触力测量。

## 4. 仿真验收

### 4.1 严格物理与接触采集

| 项目 | 标准 | 不满足时 |
| --- | --- | --- |
| 初始就位 | 位置误差 `<=3 mm`，姿态 `<=2°` | 中止该仿真试验；不同于下列无接触轨迹标准 |
| 无接触轨迹 | 三维位置 RMS `<=1 mm`，全程最大姿态误差 `<=1°` | 增益候选 100/300/1000 依次试验；没有通过者则不进行正式采集 |
| 接触参数扫描 | 摩擦、刚度、宽度端点/中点共 27 组，全部通过接触运动及卸载检查，静态传感器检查通过 | `sanity.passed=false`，禁止严格采集 |
| 前进净位移 | `Y(3s)-Y(2s)` 在 `[45,55] mm` | 接触质量不合格 |
| 返回净位移 | `Y(3s)-Y(4s)` 在 `[45,55] mm` | 同上；不是累计路程 |
| 回位误差 | `abs(Y(4s)-Y(2s))<=5 mm` | 同上 |
| Y 跟踪 | 2.00–4.00 s 最大绝对误差 `<=5 mm` | 同上 |
| X 跟踪 | 同时段最大绝对误差 `<=3 mm` | 同上 |
| 姿态 | 全部 400 帧最大误差 `<=2°` | 同上 |
| 接触比例 | 前进、返回两个阶段各 `>=95%` 帧存在工具/桌面几何接触 | 同上，不代表每帧法向力达到某个 N 值 |
| 最长断触 | 两阶段分别 `<=50 ms` | 同上 |
| 执行器饱和比例 | 全轨迹至多 `1%` 命令区间出现任一轴/物理子步饱和 | 同上；不是精确饱和持续时间 |
| 非工具碰撞 | 不允许非工具/桌面接触对出现穿透 `>1e-5 m` | 检查开启的物理步直接异常 |
| 有效接触参数 | 实际摩擦、solref、solimp 与请求值数值一致 | 不一致异常，不能只验证配置文件 |
| 卸载 | 上抬后无工具/桌面接触 | 失败；不是检查 FT 必须回到 0 N |
| 时钟/数值 | 400 帧、时间 0.01–4.00 s，100 Hz；验收时钟绝对容差 `1e-8 s`；形状正确、数值有限 | 轨迹无效，不补零伪造 |
| 静态传感器 | 中心/偏心施力的六维增量与理论值 `allclose(atol=1e-7, rtol=1e-6)`，三例全部通过 | sanity 失败 |
| sanity 来源 | 配置和当前生产源码来源匹配，且已通过并选择增益 | 旧报告、改过源码/配置后的报告不能解锁严格采集 |

上述运动质量多为轨迹结束后的门禁，并非每超过 5 mm 就立刻停止仿真。接触 Z 跟踪误差、滑动 Z 波动、法向载荷会记录，但标准接触门禁没有为其设置统一阈值，也没有统一 40 N 仿真停机线。

生产仿真执行器力矩限幅为 `[10,10,10,5,5,5] Nm`，达到限幅会裁限并统计，不等于该瞬间结束轨迹。名义 IK 参考实验另有任一参考/实际关节差 `>0.35 rad`、参考 FK 误差 `>3 mm` 或 `>2°` 即中止的可行性保护，仅用于该实验，不可套给真机。

- 论文生产配置要求 train=`1000×400×6`、validation/test 各 `100×400×6`；宽范围 1200 配置为 960/120/120，不能互相冒充。

- 其他控制器比较、惯量/刚度/摩擦/宽度扫描、单次可视化的结果只能证明各自实验。不能因研究采集/绘图完成就声称严格 sanity 或生产运动通过。

### 4.3 VAE 模型质量

| 流程 | 现有判断 | 性质 |
| --- | --- | --- |
| 普通预训练 | 200 轮，报告六通道物理 RMSE、归一化 MSE、KL、潜变量方差及固定/打乱 latent 重建 | 没有统一 N/Nm RMSE 通过线；非有限 loss/gradient 则异常停止 |
| 均值基线 | `test_mse < baseline_mse` | `beats_mean_baseline` 指标，不是普通导出的强制通过条件 |
| 坍塌警告 | 最大 latent 方差 `<1e-4`，**或**打乱后 MSE `<=原 MSE×1.01` | `collapse_warning=true`；普通流程可带警告导出，不能因此称质量合格 |
| 活跃维数 | 每维方差 `>1e-4` 的维数 | 辅助报告，不要求 5 维全部活跃 |
| 普通导出 | 已 evaluate，评估绑定的 checkpoint 哈希与当前一致 | 没有评估或评估过期则拒绝 |
| 修复/消融重建标准 | 基线 MSE>0，模型 MSE `<=0.8×均值模板基线` | 至少改善 20% |
| 修复/消融 latent 利用 | 固定 latent MSE、20 次打乱 MSE 均值均 `>=1.1×正常 MSE`，且严格大于正常 MSE | 重建和利用两项都满足才 `passed=true` |
| 小样本 AE 诊断 | 最佳 MSE 严格 `<min(0.001, 0.1×子集基线MSE)` | 只检验可拟合性，不是泛化验收 |
| 修复稳定性 | 固定种子 42 通过，42/43/44 至少两个通过；验证选型冻结后再测测试集，修复还要求验证/测试合格 | 不按测试分数选择种子；不满足不称稳定修复 |
| 真机幅值匹配实验 | 六通道同时容差为各通道真机绝对值 P95 的 10%，P95 尺度下限力 0.5 N、力矩 0.01 Nm | 仅诊断，独立检查运动合格；不用于真机停机 |

## 5. 真机数据训练与离线推理验收

这里的“真机训练”是对真机采集数据进行离线网络训练，并非训练程序直接在线驱动机械臂。

| 环节 | 现有标准/门禁 |
| --- | --- |
| 数据身份 | 正式流程必须为 real；恰好 1 条 normal 海绵探索、8 条 normal 示教；八条同一 surface_id、探索关联正确 |
| 数据维度 | 探索 `[400,6]`；每条 10 s 示教产生 25 个 2.5 Hz 策略时刻；5 帧六轴历史对应 20 个下一步高度增量目标 |
| 时钟 | 原始流严格递增、标称频率满足入口约束；完整覆盖；最大间隔和因果保持年龄均 20 ms，不使用未来帧、不得外推伪造缺失 |
| 姿态/语义 | 单位、通道顺序、右手刚体变换、位置/力参考点、补偿方式和 profile 匹配；单位四元数、数值有限 |
| 编码器 | 既有 5 维结构及 100 Hz、二阶 10 Hz 预处理匹配，参数有限，来源哈希有效；正式流程不允许 synthetic 编码器 |
| 编码器超范围 | 归一化范围为 `[0,0.9]`；真实探索越界记录 warning，不静默裁剪 |
| 编码器质量 | 发现 `passed=false`、重建/latent 利用失败或 collapse 警告，记录 `source_encoder_quality_warning`；离线训练可继续，普通部署会阻断 |
| 力反馈预处理 | 当前下游二阶 1 Hz 因果低通；部署兼容流程要求 100 Hz 过滤网格，再每 0.4 s 取样；100 Hz 保持不是 100 Hz 独立传感器采样 |
| 正式训练 | XY 10000 轮、FT 2000 轮；冻结编码器权重和预处理；不得以短跑代替完整训练后评估/导出 |
| 训练失败 | loss、梯度、更新参数非有限，编码器被修改/变为可训练、数据/模型哈希变化、续训状态/配置不一致均拒绝 |
| 补齐数据 | hold-last 必须显式记录掩码、来源和恒定尾段；raw-baseline 派生值与保留原始值一致；不能称补齐尾段是实测 |
| 离线评价 | 报 XY 与高度增量 RMSE/MAE；比较 XY 训练均值轨迹、高度零增量和训练均值基线；可做 8 折留一示教验证 |
| 导出 | 完整训练、最新且绑定正确的评估；输出仍为离线策略，`hardware_ready=false`；离线损失低不自动取得部署批准 |

**当前没有实现统一的 `XY RMSE<=X mm`、`Δh RMSE<=Y mm`、误差改善至少多少或擦拭成功率多少的真机模型导出阈值。** 普通 evaluate 是训练集记录力的预测重放，不是独立测试，更不是真机闭环验收。固定深度示教没有展示主动纠正力误差的动作，尾段补齐还可能让零高度增量基线表现变好，均须保留解释。

## 6. 真机策略推理与部署

### 6.1 当前 fixed-setup 固定安装入口

仅限相同海绵、工具安装、采集会话、冻结起点及指定模型，不是标定后通用部署。

| 项目 | 当前标准 | 行为 |
| --- | --- | --- |
| 配置/权重/数据绑定 | 策略、编码器、原始/准备数据、采集 session、训练配置及相关源码哈希一致 | 任一变化则拒绝；旧 replay 不能放行 |
| 编码器质量例外 | 明确原因、适用范围以及准确策略/编码器/session 哈希 | 仅允许已确认的质量警告例外；不豁免真实探索归一化越界 |
| 离线回放 | 报告 mode 正确、`passed=true`、bindings 与当前完全一致；无命令边界违规 | 缺失、失败或过期，`run_enabled=false` |
| 流式/批量一致性 | 8 条共 160 次高度预测，绝对差 `<=1e-8 m`、`rtol=0` | 不通过则回放失败；回放使用记录实测状态，不模拟接触动力学 |
| 现场条件 | motion_limits、startup_contact、policy_path、physical_estop、support_handoff、server_no_return 六项确认 | 未确认不能 run；现场确认本身不证明软件验证过安全 |
| 运行位置跟踪 | 参考值 5 mm | 当前 `record-only`，启动直达、策略和回撤均不因此停止 |
| 运行姿态跟踪 | 参考值 0.02 rad，约 1.146° | 当前 `record-only`，同上；起点/最终回位仍严格 |
| 预测段速度 | 相邻 0.4 s 段三维位移长度/0.4 `<=0.05 m/s` | 超过拒绝，不裁剪；不是独立实测 TCP 超速传感器 |
| 网络高度增量 | `abs(Δh)<=3 mm` | 超过拒绝，不裁剪 |
| 目标任务边界 | 相对起点 X `±5 mm`、Y `±50 mm`、总下压 `[0,20 mm]` | 目标/段端点越界拒绝，不裁剪；Z 上边界有 `1e-9 m` 数值容差 |
| 实测任务边界 | X `±5 mm`、Y `±50 mm`、下压 `<=20 mm`；允许高于起点至 2 mm | 超过停止；启动直达阶段豁免 XY 任务边界，但仍限制实测下压 20 mm |
| 实测速度/原始载荷 | 1.2 rad/s；合力运行 40 N、起点 32 N；合力矩 0.8 Nm | 不受位置/姿态 record-only 或基线扣除影响 |
| 状态/因果 FT | 状态读取 `<=20 ms`；策略时刻之前存在 FT，年龄 `[0,20 ms]`；同时检查最新原始载荷 | 失败中止 |
| 策略 100 Hz 周期 | 唤醒迟到 `<=5 ms`；发送前耗时 `<=9 ms`；含发送/日志整轮 `<=10 ms` | 超过停止，不追赶 |
| 启动直达 | 继承冻结的低速直达时长/速度；100 Hz，唤醒 5 ms、各阶段及整轮 10 ms | 超时停止；跟踪误差仍按本入口 record-only |
| 回撤 | 先在实测横向位置抬高，再横移回起点，名义 5 mm/s；单轮观测 `<=10 ms`、命令/日志整轮 `<=20 ms`；每段总时长不超过名义加 1 s | 失败中止；不可套用程序示教的回撤重排算法 |
| 最终回位 | 2 s 内通过位姿/关节/静止检查；等待交接时继续监测 | 不合格不能算完成；确认支撑后输入 `IDLE` 才正常释放 |

前 2 s 名义下压 10 mm 属于原 10 s 策略的一部分；首次高度预测在 2.0 s，目标对应 2.4 s，共 20 次。没有额外“10 N 恒力纠偏器”。`shadow` 只读，不发送目标，也不替外部操作者停止机械臂；其错误只终止自身检查。

### 6.2 默认 calibrated 通用标定入口

- 必须 real、`paper_downstream`，真实机器人/传感器/标定身份一致，prepared 数据及策略哈希正确，标定证据存在且未变，力/位置变换与训练一致。

- 运行实际位置误差超过 `max_tracking_error_m`、姿态超过 `orientation_error_limit_rad`、力/力矩/实测速率超过配置均停止；不支持 fixed-setup 的 record-only 例外。起点还检查 `max_start_error_m`。
- 预测段速度和高度增量超过批准值拒绝，不裁剪；100 Hz 唤醒迟到超过 5 ms、发送前超过 9 ms 或因果 FT 年龄超过 20 ms 则中止。不要把 fixed-setup 的发送后 10 ms 显式检查说成该入口也有同样实现。
- 当前 `airbot_deployment.json` 多项安全数值、标定和策略哈希为 `null`，确认标志为 false，因此**没有已批准的统一数值可列为实际运行阈值，入口尚未放行**。
- 正常策略结束不自动回撤；监测保持，支撑确认后 idle。与 fixed-setup 正常先抬再回位不同。

### 7.1 基础机器人控制

当前 [basic_control.json](../configs/robot_control/basic_control.json) 安全确认未完成，实际限值为 null，不能运行。下面仅是 [配置验证器](../scripts/robot_control/motion.py) 允许填写的上限，**不是已经批准的运行数值**：

| 参数 | 配置允许的最大值 |

| 平移/角速度 | 0.05 m/s / 0.3 rad/s |

| 运行关节/位置/姿态误差 | 0.15 rad / 10 mm / 0.15 rad |

### 7.2 标定质量

独立空载拟合需要至少 4 个姿态且方向设计矩阵满秩，判据为最小奇异值 `>最大奇异值×1e-8`。小于 10° 的重力方向按连通近邻组分组，用于防止重复姿态泄漏到验证集；10° 是分组/信息量诊断，不是强制机器人转动角度。

拟合报告训练/留方向组验证的力与力矩 RMSE、首尾重复漂移、条件数，但**没有统一的 N/Nm 残差或漂移批准线**。输出保持 `production_approved=false`、`hardware_ready=false`；不能自动成为有效生产标定。SDK-to-TCP、传感器轴和原点的物理标定需要独立证据，静止去皮不能替代。

出处：[空载拟合](../scripts/force_sensor/tools/fit_unloaded_calibration.py)、[多姿态采集](../scripts/force_sensor/tools/record_unloaded_session.py)、[标定记录验证](../scripts/shared/airbot_calibration.py)。

### 7.3 必须人工判断或尚无统一数字的项目

- 急停是否实际可用、停止距离/制动裕度、掉电防坠、控制释放后的支撑、机器人全臂/工具/线缆的扫掠空间与障碍。
- 海绵真实离面、表面与海绵不变、压缩容许量、温升/振动/下坠异常；配置确认不是测量证明。
